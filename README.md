# HK Advocacia - Hanilton Kleiber

Projeto de landing page institucional e sistema de contato para o escritório **Hanilton Kleiber Advocacia**, desenvolvido em Node.js com Express e integrado com Supabase.

## 🚀 Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor:
   ```bash
   npm run dev
   ```

3. Acesse no navegador:
   ```
   http://localhost:3000
   ```
